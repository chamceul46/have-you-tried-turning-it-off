Entry for the make.fun bounty **"Have You Tried Turning It Off?"**:
https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b

The entry is a single line of dialogue — a hopeless tech support agent
whose empathy is genuine and completely useless, said to a customer who
is already crying. The joke is on the agent, never the customer.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.txt — the one line, 1–199 characters, UTF-8
```

`main.py` (Python 3, standard library only) validates the line against
the bounty's gate (1–199 characters, not only white space) and writes it
to `entry.txt` in the output directory.
